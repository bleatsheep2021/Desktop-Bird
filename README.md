# Load an Unpacked Chrome Extension

1. Open Google Chrome.

2. Go to:

```
chrome://extensions
```

3. Turn on:

```
Developer mode
```

(top-right corner)

4. Click:

```
Load unpacked
```

5. Select your extension folder.

6. The extension will now appear in the list and can be tested.

If you make changes to the extension files:

1. Return to:

```
chrome://extensions
```

2. Click:

```
Reload
```

on your extension.
